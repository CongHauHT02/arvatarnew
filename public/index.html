Cài Đặt Kết Nối Máy Chủ Sẵn sàng

Vì chạy trên Vercel (Web Sandbox), trình duyệt cần kết nối thông qua WebSocket Proxy để chuyển tiếp gói tin tới Server Java (Port 19128).

💡 Hướng dẫn phím bấm máy tính:

  • Mũi tên hoặc W-A-S-D: Di chuyển (Phím 2-4-6-8)
  • Phím Enter hoặc Space: Phím Chọn / OK (Phím 5)
  • Phím F1 / Q: Menu Trái
  • Phím F2 / E: Menu Phải
  • Các phím 0-9: Bàn phím số gõ chat và chọn vật phẩm

⚙️ Hướng Dẫn Vận Hành Server & Vercel

Để game hoạt động hoàn chỉnh khi bạn đưa web lên Vercel, hãy làm theo quy trình sau:

1. Hiểu cách hoạt động khi dùng Vercel:

  • Vercel: Đảm nhận lưu trữ giao diện Web, Trình giả lập HTML5/Wasm, Trang đăng ký tài khoản và API.
  • Java Server (`Avatar2D-1.0-SNAPSHOT.jar`): Chạy trên máy tính (localhost) hoặc Cloud VPS (Render/Railway/VPS).
  • WebSocket Proxy (`ws-proxy.js`): Nhận kết nối WebSocket từ trình duyệt và chuyển sang cổng 19128 của Java Server.

2. Chạy Java Server trên máy của bạn:

# 1. Cài đặt OpenJDK 17 (nếu chưa có)
winget install Microsoft.OpenJDK.17

# 2. Khởi tạo database MySQL 'avatar_2x' và import file 'database/avatar_2x.sql'

# 3. Khởi động Server Game:
java -jar target/Avatar2D-1.0-SNAPSHOT.jar

3. Khởi động WebSocket Proxy:

# Cài đặt thư viện node:
npm install

# Khởi chạy Proxy WebSocket lắng nghe cổng 19129:
node ws-proxy.js

4. Public Server ra Internet để Web Vercel kết nối:

Nếu bạn chạy server trên máy tính cá nhân, hãy dùng ngrok hoặc Cloudflare Tunnel để mở cổng 19129 ra ngoài:

ngrok http 19129

Sau đó dán link wss://...ngrok-free.app vào ô Địa chỉ WebSocket Proxy ở tab Chơi Trên Web!
